About the Project

What is a CubeSat OBC?

The On-Board Computer (OBC) is the central nervous system of any satellite. It handles command execution, data acquisition, storage, and coordination of all subsystems. Without a reliable OBC, a CubeSat cannot function in space.

Why This Matters

CubeSats provide data for precision agriculture, disaster monitoring, environmental protection, and remote connectivity — areas vital to Algeria's development. This project builds local expertise in space technology and creates a foundation for future Algerian student satellite missions.

Technical Approach

We are designing a custom PCB based on the STM32F407VGT6 microcontroller, running FreeRTOS for real-time multitasking. The system includes external memory, multiple communication interfaces (I²C, SPI, UART, CAN), and fault-tolerant features like a watchdog timer.

Key Features

⚡

STM32F407VG

168 MHz ARM Cortex-M4 with FPU, 1 MB Flash, 192 KB RAM. Flight heritage on NASA CubeSat missions.

🔄

FreeRTOS

Real-time multitasking kernel for deterministic task scheduling and inter-task communication.

💾

Tiered Memory

64 MB SRAM, 1 GB NAND Flash, and microSD card slot for robust data storage.

🔌

Multiple Interfaces

I²C, SPI, UART, CAN, USB — compatible with standard CubeSat subsystems.

🛡️

Fault Tolerance

External watchdog timer, current limiting, and software-based recovery mechanisms.

🔋

Power Management

Efficient buck converter (16.8V → 3.3V) with load switching and current monitoring.
